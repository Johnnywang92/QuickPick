🍎 macOS 首次安装提示解决指南

为什么首次打开提示「无法验证开发者」或「已移入废纸篓」？

由于 QuickPick 为独立开源项目，未向苹果支付商业证书年费，属于 macOS Gatekeeper 正常拦截。只需打开系统终端，运行上方提供的放行命令：xattr -cr /Applications/QuickPick.app 即可秒级开启。

支持 Windows 和 Intel Mac 吗？

目前 GitHub Releases 提供编译好的 macOS Apple Silicon (M1/M2/M3/M4) DMG 安装包。Windows 与 Intel Mac 正在适配准备中，开发者也可通过 README 指引本地编译体验。
