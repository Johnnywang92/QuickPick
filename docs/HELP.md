## 1. 安装与启动

### Q1.1 打开时提示“无法验证开发者”或“已损坏，无法打开”
**关键词**：打不开 无法验证 开发者 Gatekeeper 已损坏 废纸篓 隔离

QuickPick 目前没有做 Apple 公证，所以 macOS 首次打开时会拦截。任选一种方法：
1. 打开「系统设置 → 隐私与安全性」，下拉找到 QuickPick 的提示，点「仍要打开」。
2. 在访达的「应用程序」里，按住 `Control` 键点击 QuickPick，选「打开」。
3. 在终端运行：
   ```bash
   xattr -cr /Applications/QuickPick.app
   ```

### Q1.2 支持哪些系统？
**关键词**：系统 Windows Intel Apple Silicon M1 M2 M3 M4

当前发行版仅支持 **Apple Silicon（M 系列）Mac**，安装包名为 `QuickPick_0.2.0_aarch64.dmg`。Windows 和 Intel Mac 暂无官方安装包。

### Q1.3 怎么安装与升级？
**关键词**：安装 升级 更新 dmg 拖拽 卸载

1. 双击 DMG，把 QuickPick 拖进「应用程序」。
2. 升级时先退出 QuickPick，再用新版本覆盖旧的。
3. 卸载：把 `/Applications/QuickPick.app` 拖进废纸篓。如要同时清理数据，见 [Q8.3](#q83-如何彻底清除数据)。

## 2. 导入与支持格式

### Q2.1 支持哪些照片格式？
**关键词**：格式 RAW JPG PNG WebP ARW CR2 CR3 NEF DNG RAF ORF RW2 PEF SRW 不支持

| 类型 | 扩展名 |
|---|---|
| RAW | `arw` `cr3` `cr2` `nef` `dng` `raf` `orf` `rw2` `pef` `srw` |
| 普通图片 | `jpg` `jpeg` `png` `webp` |

扩展名不区分大小写。其他格式（如 HEIC、TIFF、视频）不会被识别。

### Q2.2 导入文件夹后有些照片没显示
**关键词**：缺失 不显示 少照片 没出现 导入

- 先检查这些照片的扩展名是否在 [Q2.1](#q21-支持哪些照片格式) 的列表里。
- 检查是否被顶部的筛选条件过滤掉了。按 `Esc` 可以重置筛选队列。
- 如果是很新的相机机型，RAW 解码依赖 LibRaw，可能暂不支持，请在反馈时提供机型。

### Q2.3 RAW 照片看起来比相机直出的 JPG 暗或颜色不同
**关键词**：RAW 颜色 偏色 偏暗 缩略图 内嵌预览

QuickPick 主要使用 RAW 里的内嵌预览图做快速浏览，并不是完整的 RAW 冲洗。预览的色彩由相机内部风格决定，所以与 Lightroom 等软件完整渲染的结果会有差异。它只用于选片，不能代替后期。

### Q2.4 移动或重命名了照片文件夹，之前的选片记录还在吗？
**关键词**：移动 文件夹 重命名 丢失 重新定位 路径

照片身份基于相册内的相对路径生成，所以整个文件夹一起移动后，选片记录可以保留。但如果单张照片改了名或被移出文件夹，那张照片的记录就对不上了。

### Q2.5 应用刷新或重新启动后，当前选片进度会丢失吗？
**关键词**：刷新 重启 保存 丢失 恢复 欢迎页 进度 会话 记忆

不会。QuickPick 具备完整的**项目状态与工作区持久化记忆**：
1. 所有的勾选、排除、待考虑、标签与调色决定都会实时写入应用本地的安全数据库。
2. 打开相册时会自动记忆当前活动工作区路径。即使遇到意外刷新或重新启动应用，都会自动无缝恢复至您正在浏览的相册与当前照片位置，绝不会退回选择文件夹欢迎页。

## 3. 选片与快捷键

### Q3.1 按空格没反应 / 快捷键失效
**关键词**：快捷键 没反应 失效 空格 输入法

1. 确认焦点不在输入框里（例如批注框）。在输入框里打字时，单键快捷键会被让给输入。
2. 切换成**英文输入法**。中文输入法下，部分字母键可能被输入法拦截。
3. 确认没有弹窗打开。按 `Esc` 关闭弹窗后再试。
4. 完整快捷键见 [第 10 节](#10-快捷键速查)。

### Q3.2 选错了怎么办？
**关键词**：撤销 Cmd+Z 误操作 恢复 批量

按 `Cmd + Z`（Windows/Linux 为 `Ctrl + Z`）撤销上一次选择操作，批量操作可以一次整体撤回。

### Q3.3 「选择 / 待考虑 / 不选」有什么区别？
**关键词**：selected skipped 待考虑 排除 标记 状态

- **选择**（`Space`）：保留的照片。被选择的照片会受到保护，批量剔除时不会被误伤。
- **待考虑**（`M`）：暂时拿不准，之后可以集中复核。
- **不选**（`N`）：明确排除。

### Q3.4 只想看没选过的或只看选中的照片
**关键词**：筛选 过滤 队列 Esc 重置

用界面上方的筛选工具栏切换。要回到全部照片，按 `Esc` 重置筛选队列。`Home` / `End` 会跳到当前筛选结果的第一张或最后一张。

### Q3.5 两张很像的照片怎么挑？
**关键词**：对比 连拍 PK 分屏 相似

- `C`：进入双图分屏比较，`S` 互换左右两张。
- `P`：连拍极速对决，两两 PK 淘汰。
- `Z`：切换到 100% 像素查焦，检查对焦是否准确。

## 4. 浏览与显示

### Q4.1 照片加载慢、翻页卡顿
**关键词**：卡 慢 加载 性能 缓存 大图

- 第一次打开某个文件夹时需要生成预览缓存，会慢一些，之后会明显变快。
- 照片放在移动硬盘、网络盘或 NAS 上时，读取速度取决于硬盘本身。建议先拷到本地 SSD 再选片。
- 缓存放在系统应用数据目录，上限为 1 GiB，超出后自动淘汰最久未用的缓存。

### Q4.2 构图参考线不见了 / 想换一种参考线
**关键词**：构图线 三分法 黄金螺旋 网格 参考线

按 `O` 循环切换：三分法、黄金螺旋、黄金分割、动态对称、中心十字与地平线，再按一次关闭。`Shift + O` 旋转黄金螺旋的朝向。

### Q4.3 想要无干扰地看片
**关键词**：沉浸 全屏 Lights Out 看片模式

按 `Tab` 或 `Shift + F` 进入沉浸看片模式，再按一次退出。

### Q4.4 想对比调色前后
**关键词**：对比 原片 Before After 反斜杠

按住 `\` 键，临时显示未调色的原片，松开恢复。

### Q4.5 大图右键菜单有什么功能？
**关键词**：右键 菜单 快捷键 查焦 调色 路径 标记 刷新

在大图上点击右键，可呼出沉浸式专业快捷菜单：
- **重新载入当前大图**：在原地重新解码并渲染当前底片，绝不会刷新整个应用或重置选片进度。
- **1:1 像素细节查焦 / 适应屏幕**（`Z`）：瞬间放大至感光元件 100% 细节对焦点，或居中适配窗口。
- **快速调色工作台**（`E`）：打开参数相框与色彩微调。
- **复制照片文件路径**：复制文件的绝对路径到剪贴板，方便在访达或终端定位。
- **标记状态**：快速标记为「已选」（`Space`）、「待考虑」（`M`）、「不选」（`N`）。

### Q4.6 为什么后台检查图片不会拖慢看片和翻页速度？
**关键词**：卡 慢 检查 后台分析 速度 避让 优先 SMB 性能

QuickPick 采用了**视口与交互零阻塞避让机制**：
1. **交互绝对优先**：只要您在轻扫触控板、滚动胶片栏或切换照片，后台的闭眼/模糊深度分析会自动挂起避让，将 100% 的网络带宽、磁盘 I/O 与 CPU 周期留给当前照片的大图解码与渲染。
2. **GPU 纹理后台预热**：系统在环形预取相邻照片时，会提前在后台预热 GPU 纹理，翻页时享受 0ms 瞬间上屏。
3. 只有在您停止翻页操作且当前大图加载完成后，后台才会平稳进行分析，绝不影响选片节奏。

## 5. 缺陷提示：闭眼、模糊、连拍

### Q5.1 应用说某张照片闭眼或模糊，但我觉得没问题
**关键词**：闭眼 模糊 脱焦 误判 不准 缺陷 Blink Blur

闭眼、脱焦和连拍冗余都是**算法给出的提示**，只作为人工复核的参考，不会自动删除任何照片，也可能误判。例如微笑眯眼、逆光、浅景深下的脸部都容易被判错。最终以你自己的判断为准。

### Q5.2 一键剔除会不会误删好片？
**关键词**：漏斗 一键剔除 粉碎 误删 保护 撤销

- 已被你标为「选择」的照片是**受保护**的，不会被批量剔除。
- “剔除”只是在 QuickPick 里把照片标记为不选，**不会删除原始文件**。
- 随时可以用 `Cmd + Z` 撤销。

### Q5.3 人脸特写（F）里没有脸或脸不全
**关键词**：人脸 特写 F 没检测到 侧脸 小脸

人脸检测在侧脸、遮挡、很小的脸、强逆光时可能漏检。这种情况需要用 `Z` 手动放大检查。

## 6. 相框、调色与 LUT

### Q6.1 相框上的相机型号显示不对或为空
**关键词**：相框 EXIF 相机型号 镜头 空白 参数

相框文字来自照片自身的 EXIF 信息。如果照片被微信、修图软件处理或导出时去掉了 EXIF，就没有可显示的相机参数。这不是软件错误。

### Q6.2 怎么用相框和调色台？
**关键词**：E 相框 调色 模板 复制 剪贴板 Cmd+C 数字键

1. 按 `E` 打开相框与调色台。
2. 用数字键 `1 ~ 6` 切换相框模板。
3. 调整完成后，按 `Cmd + C` 把带框的图片复制到剪贴板，可以直接粘贴到聊天软件或网页。
4. 双击滑块的标签，可以让该项归零。

### Q6.3 怎么导入自己的 LUT？
**关键词**：LUT cube 导入 自定义 滤镜 调色

QuickPick 支持导入 `.cube` 格式的 3D LUT 文件。按 `L` 开关 LUT 调色，按 `B` 切换黑白影调检查。导入失败时请确认文件是标准 `.cube` 格式，且不是损坏或被截断的文件。

### Q6.4 调色会修改我的原片吗？
**关键词**：修改原片 非破坏 只读 调色保存

不会。调色、相框和 LUT 都只作用于屏幕预览或导出的新文件，**不会改写原始照片**。

## 7. 导出与交付

### Q7.1 导出时提示“导出目标目录不能是源相册目录或其子目录”
**关键词**：导出 目标目录 源目录 子目录 不能 失败

这是保护机制，防止导出文件覆盖或污染原片。请**新建一个空文件夹**，位置不要在照片所在的文件夹里，再通过系统选择器选择它。

### Q7.2 提示“目标文件已存在”或出现同名冲突
**关键词**：同名 冲突 已存在 覆盖 重命名 跳过

QuickPick 不会静默覆盖已有文件。遇到同名冲突时，可以选择跳过或自动重命名，也可以换一个新的目标文件夹，或在保存对话框里换一个文件名。

### Q7.3 提示“检测到目标路径与源底片具有相同 Inode”
**关键词**：Inode 硬链接 符号链接 软链接 别名 自覆盖

目标位置通过硬链接或符号链接，指向了原片本身。为避免自我覆盖，导出被阻断。请选择一个**真实的、独立的文件夹**，不要使用别名或快捷方式。

### Q7.4 导出的文件和原片不一致？
**关键词**：校验 SHA-256 哈希 完整性 损坏

导出采用 SHA-256 哈希校验和源文件快照校验。如果提示源文件在导出过程中发生了变化，说明原片在导出时被其他程序修改过。请关闭相关程序后重新导出。

### Q7.5 导出 JPEG 的尺寸和质量范围
**关键词**：JPEG 品质 长边 尺寸 分辨率

- JPEG 品质范围：**40 ~ 100**。
- JPEG 长边范围：**640 ~ 8192 像素**。

超出范围会报错，请调整后重试。

### Q7.6 AirDrop 用不了
**关键词**：AirDrop 隔空投送 分享 无法

- AirDrop 仅在 macOS 上可用。
- AirDrop 分享的是生成的 JPEG。如果没有成功生成 JPEG，或分享列表为空，就无法分享。请先确认有照片被选中且导出成功。
- 确认两台设备的蓝牙、Wi-Fi 和 AirDrop 接收设置都已开启。

### Q7.7 导出被中断了，怎么办？
**关键词**：中断 恢复 导出任务 未完成 重启

未完成的导出任务记录保存在本地数据库里，重新启动 QuickPick 后会尝试恢复。如果提示“相同导出任务已在运行”，说明上一个任务还在后台，请等它结束后再操作。

### Q7.8 导出时需要同时带上 XMP 吗？
**关键词**：XMP 伴侣文件 sidecar Lightroom 同名

可以在导出设置中勾选是否包含同名 `.xmp` 伴侣文件。XMP 默认**不会**写入照片目录，只会随导出写到你选定的目标文件夹里。

## 8. 数据、缓存与隐私

### Q8.1 QuickPick 会上传我的照片吗？
**关键词**：隐私 上传 联网 云端 安全

不会。当前版本没有账号、云同步、遥测或崩溃上报。照片只在本机被只读访问。详见 [PRIVACY.md](../PRIVACY.md)。

### Q8.2 我的选片记录存在哪里？
**关键词**：数据库 SQLite 选片记录 存储位置 备份 应用数据

选片、批注和项目状态保存在本机应用数据目录的 SQLite 数据库中（macOS 通常在 `~/Library/Application Support/com.quickpick.triage`）。QuickPick 会自动做备份。

### Q8.3 如何彻底清除数据？
**关键词**：清除 删除 缓存 重置 卸载 清理空间

1. 退出 QuickPick。
2. 删除应用数据目录 `~/Library/Application Support/com.quickpick.triage`（会清除全部选片记录和预览缓存，**无法恢复**）。
3. 只想释放空间时，只需要删除其中的预览缓存目录，选片记录会保留。

### Q8.4 提示“项目数据库已损坏”
**关键词**：数据库 损坏 完整性 备份 恢复 无法写入

QuickPick 会先尝试用自动备份恢复。如果备份也不可用，它会**停止写入**，以免进一步破坏已有数据。请先不要删除应用数据目录，把整个目录复制一份保存，再通过反馈渠道联系我们。

### Q8.5 会不会修改我的原片目录？
**关键词**：只读 原片 修改 写入 源目录 安全

不会。扫描、浏览、标记、调色和导出过程不会修改、重命名、覆盖或删除原片，也不会在照片所在目录写入缓存或配置。

### Q8.6 处理他人照片（婚礼、客户）需要注意什么？
**关键词**：人脸 肖像 隐私 授权 个人信息

QuickPick 的人脸分析只在本机运行，不用于识别身份，也不上传。但如果你给他人拍摄并交付照片，需要自行遵守当地法律，取得拍摄和使用所需的授权。详见 [PRIVACY.md](../PRIVACY.md)。

## 9. 错误信息速查表

| 提示内容 | 含义与处理 |
|---|---|
| 导出目标目录不能是源相册目录或其子目录 | 换一个不在照片目录里的新文件夹。见 [Q7.1](#q71-导出时提示导出目标目录不能是源相册目录或其子目录) |
| 导出目录不能包含源照片 | 目标文件夹里已有源照片，请换一个空文件夹 |
| 导出目标文件夹不存在，请通过系统选择器明确选择一个已有文件夹 | 目标文件夹被删除或移动，请重新选择 |
| 导出目标不是文件夹 | 选到了文件，请选择文件夹 |
| 目标文件已存在。为避免覆盖，请在保存对话框中选择新的文件名 | 换一个文件名。见 [Q7.2](#q72-提示目标文件已存在或出现同名冲突) |
| 检测到目标路径与源底片具有相同 Inode… | 目标是原片的别名，见 [Q7.3](#q73-提示检测到目标路径与源底片具有相同-inode) |
| 待导出照片列表为空 / 没有可导出的照片 | 先选中至少一张照片再导出 |
| 相同导出任务已在运行 | 等待上一个任务结束 |
| JPEG 品质必须在 40 到 100 之间 | 调整品质 |
| JPEG 长边必须在 640 到 8192 像素之间 | 调整尺寸 |
| JPEG 导出目标不是有效文件夹 | 重新选择导出文件夹 |
| AirDrop 仅在 macOS 上可用 | 只能在 Mac 上使用 AirDrop |
| 没有成功生成可供 AirDrop 的 JPEG / 分享列表为空 | 先确保有选中的照片并生成成功 |
| 清单内容不能为空 / 清单保存路径不能为空 | 没有可导出的清单内容，请先选片 |
| 清单目标目录不存在或不是文件夹 | 重新选择保存位置 |
| 项目数据库已损坏且没有可用备份；已停止写入以保护现有数据 | 见 [Q8.4](#q84-提示项目数据库已损坏) |
| 备份恢复后的项目数据库仍未通过完整性检查 | 同上，请保留数据目录并反馈 |
| 项目没有已索引照片，无法安全确认新的源目录 | 重新定位文件夹时，新文件夹里必须有原来的照片 |
| 场景数据超过 1 MB 安全限制 | 场景数据过大，请精简后再试 |
