# QuickPick（极选）

<p align="center">
  <strong>专为专业摄影师与深度影像爱好者打造的本地极速选片与构图调色工作台</strong><br>
  零上传 · 100% 原片只读安全 · 毫秒级原生解码 · 电影级调色与审美相框
</p>

---

QuickPick 是面向摄影师、修图师与普通用户的本地选片与交付工具，帮助用户从动辄数千张 RAW/JPEG 底片中极速完成浏览、筛选、智能复核、辅助调色与安全导出。

**核心安全承诺**：扫描、浏览、AI 辅助分析、构图参考与标记过程**绝不修改、重命名、覆盖或删除任何原始照片文件**，绝不在源照片目录写入任何临时文件、缓存、锁或项目元数据。

## ✨ 核心特性一览

### 1. ⚡ 极致选片效率：【废片一键粉碎漏斗 (Blink & Blur Funnel)】
- **4 大缺陷智能筛查**：自动聚类并筛选出 👁️ **闭眼缺陷**（双眼睁开度算法精准捕获）、🌫️ **严重脱焦 / 模糊**（拉普拉斯锐度方差检测）以及 📸 **连拍冗余劣选**（相似连拍中 AI 次选废片）。
- **🛡️ 绝对安全保障（已保留强保护）**：任何已被摄影师手动标记为 `selected`（保留）的照片均被强制锁定保护并附带金标，禁止批量剔除，彻底杜绝误伤好片！
- **一键粉碎与原子撤销**：一键批量标记为 `skipped`（剔除），支持随时按 **`Cmd + Z`** 毫秒级撤销恢复。

### 2. 📐 选片与构图辅助：【经典构图参考线 (Composition Grids)】
- **5 大经典摄影构图线**：
  - 📐 **经典三分法 (Rule of Thirds)**：3×3 经典黄金九宫格，含 4 大黄金趣味交点（Power Points）同心微圆点标记；
  - 🌀 **斐波那契黄金螺旋 (Golden Spiral)**：$\phi \approx 1.618$ 自然生长螺旋曲线，支持 4 象限顺时针旋转（按 **`Shift + O`** 秒级翻转）；
  - ⚖️ **黄金分割比例网格 (Golden Ratio / Phi Grid 1:0.618:1)**：重心内聚，契合经典人像与故事感特写；
  - 📐 **对角线与动态对称 (Diagonal & Dynamic Symmetry)**：四角对角线与互补垂足构成的黄金三角形网格；
  - 🎯 **中心十字与地平线校准 (Center Crosshair & Horizon Guide)**：水平轴配备高精度毫米级刻度与中央瞄准环，专攻地平线倾斜校正与建筑透视。
- **Pixi.js v8 硬件加速与自适应逆缩放**：无论全屏适配还是 100%/400% 细节放大，线条始终保持 $1.25\text{px}$ 物理像素锐利宽度，绝不虚化变粗。
- **全能交互**：快捷键 **`O`** 循环盲打秒切，右上角悬浮控制栏提供 4 色高对比切换（暖金/亮白/科技青/深黑）与 20%~100% 透明度调节。

### 3. 🎨 相机 EXIF 参数相框与选片快速调色工作台 (Frame & Adjust)
- **快捷键 `E` 瞬时呼出**，提供高审美摄影质感与 100% IP 知识产权合规设计：
  - 🖼️ **6 大合规艺术相框模板**（经典白底、暗夜黑曜、琥珀极简、电影宽幅 2.39:1、复古相纸、极简角标），按数字键 `1 ~ 6` 盲打秒切；
  - 🖋️ **原创高精几何摄影徽标**：多边形光圈叶片、精密对焦刻度、35mm 胶卷孔与极简旁轴，杜绝商业商标侵权；
  - ✨ **算法一键智能调光 (Auto Tone Engine)**：Rec.709/sRGB 色彩空间自适应映射，直方图均衡与白平衡色温色调一键校正；
  - 🎚️ **彩色物理渐变滑槽与微交互**：冷暖/色调物理渐变槽、双击标签瞬时归零、长按 **`\`** 键瞬时原片对比 (Before/After)；
  - 📋 **`Cmd + C` 一键复制带框高清图到剪贴板**：直接去微信、飞书、小红书网页端粘贴发送，支持 AirDrop 隔空投送。

### 4. 🎞️ 3D LUT 胶片电影级调色与莱卡高反差黑白影调
- 内置经典胶片色调（柯达 Portra 400、富士 Classic Chrome、Pro Neg Hi、莱卡高反差黑白等）。
- **`L` 键**开关 3D LUT 胶片调色，**`B` 键**一键切入莱卡高反差黑白检查画面明暗层次与微反差焦点。
- 支持导入自定义 `.cube` 3D LUT 查找表文件，基于 Rust 多线程与 WebGPU/WebGL 实时 60-120fps 映射渲染。

### 5. 👥 智能故事线、人物记分板与离线协同
- **剧本式故事线识别 (`StorylineBar`)**：时序跨度智能聚合场景分段，规划各环节出片配额目标。
- **至亲人物出场记分板 (`FamilyRadarModal`)**：人像聚类与主客追踪，确保婚礼/活动中核心重要人物不漏片。
- **连拍极速对决 (`P`)**：两两 PK 淘汰制，秒选最佳神态。
- **人脸特写抽屉 (`F`)**：一键并排切片所有人物面部 100% 局部焦点，秒查闭眼、虚焦与面部微表情。
- **离线双人协同选片 (`MergeSelectionsModal`)**：摄影师与客户/双机位离线独立挑片，工程文件无冲突一键智能合并。

| **`O`** | 循环切换经典构图参考线（三分法 / 黄金螺旋 / 黄金分割 / 动态对称 / 中心地平线 / 关） |
| **`Shift + O`** | 顺时针旋转黄金螺旋朝向（四象限轮换） |

| **`L`** | 打开 / 关闭 3D LUT 胶片电影级调色 |
| **`B`** | 一键切换莱卡高反差黑白影调检查 |

| **`F`** | 打开 / 关闭 人脸特写抽屉 |
| **`Z`** | 100% 真实传感器像素点对点查焦 / 全屏适配切换 |

| **`Home` / `End`** | 跳到当前筛选队列首张 / 末张 |
| **`Esc`** | 退出对比模式、关闭弹窗或重置筛选队列 |

## 🔒 数据安全与底层设计

### 1. 源数据绝对只读
- 源目录及内部照片在全生命周期内保持物理只读（`ReadOnly`）。
- 用户的决定、标签、批注和项目状态统一安全保存在 Tauri 应用本地的 SQLite 数据库。
- 预览缓存放置于系统应用数据目录，设有严格的 1 GiB 上限及自适应 LRU 淘汰机制。

### 2. 导出防护安全红线
- 导出目标目录必须由用户明确选择，**严禁选择源目录或其子目录**。
- 目标目录存在同名冲突时提供智能跳过或自动重命名，**绝不静默覆盖**。
- 导出时采用 SHA-256 哈希校验与源文件快照校验，确保文件完整无损。
- 支持原生导出 TXT、CSV、JSON 选片清单与 XMP 伴侣文件。

## 📥 下载与安装

前往 [GitHub Releases](https://github.com/Johnnywang92/QuickPick/releases) 下载最新发行版：

- **macOS (Apple Silicon M1/M2/M3/M4 系列)**：
  1. 下载 `QuickPick_0.2.0_aarch64.dmg` 安装镜像；
  2. 双击打开，将 **QuickPick** 图标拖拽至 **Applications** 应用程序文件夹即可。
- **Windows / Intel Mac**：支持筹备中，可参照后文开发指南自行本地编译。

> [!TIP]
> **🍎 macOS 首次打开安全提示**
> 由于开源个人软件未加入高成本商业公证，首次在 macOS 打开可能提示“无法验证开发者”或“已被移入废纸篓”。此为 macOS Gatekeeper 机制正常拦截：
> 1. 打开系统的 **「设置」->「隐私与安全性」**，下拉找到 QuickPick 提示，点击 **「仍要打开」**；
> 2. 或在访达 Applications 文件夹中，**按住 Control 键点击图标并选择「打开」**；
> 3. 或打开系统终端执行解除隔离属性命令：
>    ```bash
>    xattr -cr /Applications/QuickPick.app
>    ```

## 🛠️ 本地开发与质量门禁

### 环境要求
- Node.js 18+
- Rust 1.75+
- LibRaw 动态库 与 `pkg-config`

### macOS 安装依赖与启动
```bash
brew install libraw little-cms2 pkg-config
npm install
npm run tauri dev
```

### 自动化质量门禁
提交代码或 PR 前请执行：
```bash
npm run gate
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
git diff --check
```
`npm run gate` 会严格校验：
- Vitest 前端单元测试（31 套套件、179+ 项单测）
- TypeScript 严格类型检查 (`tsc --noEmit`)
- Vite 生产环境构建与 Chunk 体积约束（单文件严格小于 500 KiB）
- Rust Clippy 静态检查与 67 项 Rust 核心引擎自动化测试

### macOS Release DMG 构建
```bash
bash scripts/bundle_macos_libs.sh
npm run tauri build -- --bundles app
npm run verify:mac-bundle
bash scripts/build_dmg.sh
```
